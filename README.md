# Money Planner

A simple static personal finance planner for GitHub Pages.

## Features
- Income and expense tracking
- Current and future planned expenses
- Monthly dashboard
- Remaining money and expense rate
- Categories
- Paid/planned status
- Recurring marker
- Six-month visual overview
- JSON export/import backup
- Data saved locally in the browser
- No backend, database or API required

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.

The site will be available at your GitHub Pages URL.

Important: data is stored in the browser's localStorage. Export a backup periodically if the data matters to you.
